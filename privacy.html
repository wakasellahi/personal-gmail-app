Privacy Policy

Last updated: 11-23-2026

Personal Gmail is a private desktop tool used only by its owner, with the owner's own Google Account.

What it accesses

With the owner's approval, it can access the owner's Gmail, Google Calendar and Google Contacts.

How the data is used

The data is used only to carry out tasks the owner requests. The owner may use an AI assistant for those tasks, and the assistant's provider then processes the data needed for that request.

Storage

The sign-in token is stored on the owner's own computer. This website collects no data.

Sharing

The data is not sold and is not used for advertising.

Removing access

The owner can remove this tool's access at any time in the Google Account security settings.

Questions

Questions can be raised through this page's GitHub repository.
